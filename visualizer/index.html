THE IMPLEMENTED SUBSET
A small instruction set.
A real assembler.
ByteForge implements these forms for eight base 64-bit registers. It does not claim support for the full x86-64 ISA.
InstructionSupported formEncoded size
MOVr64, integer or symbol address10 bytes
ADD / SUB / CMPr64, signed imm327 bytes
XORr64, r643 bytes
JMPcode label · fixed rel325 bytes
JE / JNEcode label · fixed rel326 bytes
SYSCALLno operands2 bytes
DBASCII strings and numeric bytes, after codeLength of data
RAX · RBX · RCX · RDX · RSI · RDI · RBP · RSP
i
TraceLab models ZF, stdout write (syscall 1) and exit (60). Other syscalls and memory outside mapped DB data fault explicitly. Detailed opcode fields are reserved for the next educational milestone.


    
ONE ASSEMBLER. TWO WAYS TO EXPLORE.
From the terminal.
Python 3.10+ and the standard library. No assembler, linker, package install or frontend build step.
01 / BUILD A NATIVE ELF
Assemble a file
python -m byteforge.cli examples/hello.asm -o build/hello
Works on Windows and Linux. Choose a fresh output path: existing files are not overwritten. Run the executable only on Linux x86-64 or compatible WSL.
chmod +x build/hello
./build/hello
02 / TRACE WITHOUT NATIVE EXECUTION
Open the debugger
python -m byteforge.trace_cli examples/loop.asm --interactive
Available on Windows and Linux. Use next, back, registers, memory ADDRESS LENGTH, continue, reset and quit.
Simulated exit status is separate from the debugger's process exit code.
03 / OPEN TRACELAB
The same engine, in your browser
python -m byteforge.trace_server --port 8765
Open http://127.0.0.1:8765. The server is loopback-only. Keep it running while you explore; stop it with Ctrl+C.
